# Module 1 — Phishing Simulation

## 1. Objective

To configure and conduct a controlled phishing simulation using GoPhish to understand email-based phishing techniques, campaign management, landing-page configuration, and user interaction tracking.

## 2. Tools Used

- GoPhish
- Kali Linux
- Web browser

## 3. Environment Setup

GoPhish was configured and executed locally on Kali Linux.

The following services were identified:

| Service | Port | Purpose |
|---|---:|---|
| GoPhish Admin Server | 3333 | Campaign and configuration management |
| GoPhish Phishing Server | 80 | Landing-page delivery and click tracking |

## 4. Campaign Configuration

The following components were configured:

- Email template: Microsoft-themed test template
- Landing page: Configured landing page
- User group: Controlled test recipient
- Sending profile: Configured email sending profile
- Campaign: Test phishing campaign

## 5. Simulation Execution

A controlled test campaign was launched using a test email account.

The test email was successfully received, and the embedded tracking link was opened in a browser.

## 6. Click Tracking Verification

The GoPhish campaign results timeline recorded:

- Campaign Created
- Email Sent
- Clicked Link events

Five click events were visible in the observed campaign timeline.

These events confirm that tracked requests were recorded. They do not independently establish that all events were generated by deliberate human interaction.

## 7. Findings

- GoPhish admin and phishing listeners were operational.
- The phishing landing page was accessible locally.
- The campaign successfully delivered a test email.
- Click tracking was operational during the test.

## 8. Limitations

- Automated link-scanner activity has not yet been ruled out.
- Form submission tracking was verified during a subsequent controlled test using dummy values only. No real credentials were used.
- The simulation was conducted in a controlled test environment.

## 9. Conclusion

The initial phishing simulation environment was successfully configured and tested. Email delivery and click-event recording were verified, establishing the foundation for subsequent email security analysis and incident investigation.
